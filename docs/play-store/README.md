## Play Console에서 직접 하셔야 하는 단계

1. https://play.google.com/console 에 로그인 → 개발자 계정 등록 (최초 1회, 등록비 US$25, 본인 인증)
2. **앱 만들기**: 앱 이름 `헬스 플래닛`, 기본 언어 `한국어`, 유형 `앱`, `무료` 선택
3. **앱 설정 (대시보드 체크리스트)**
   - 개인정보처리방침: 위 URL 입력
   - 앱 액세스 권한: "모든 기능을 제한 없이 사용 가능"
   - 광고: "광고 없음"
   - 콘텐츠 등급: 설문 작성 (폭력/성적/도박 등 모두 "아니요" → 전체이용가)
   - 타겟층: 만 18세 이상 권장 (13세 이상도 가능)
   - 데이터 보안: "사용자 데이터를 수집하거나 공유하지 않음" (기기 내부 저장만, 전송 없음)
   - 건강 앱 선언: 운동/피트니스 계획 기록 앱, 건강 데이터 수집 없음
   - 정부 앱 / 금융 기능: 해당 없음
4. **스토어 등록정보**: 위 텍스트와 아이콘, 피처 그래픽, 스크린샷 업로드
5. **Play 앱 서명**: Google이 관리하는 앱 서명 키 사용 (기본값)
6. **테스트 및 출시**
   - ⚠️ 2023년 11월 이후 만든 **개인 개발자 계정**은 프로덕션 출시 전에
     **비공개 테스트(테스터 12명 이상, 14일 연속)**를 먼저 진행해야 합니다.
   - 비공개 테스트 트랙에 `app-release.aab` 업로드 → 테스터 이메일 등록 → 14일 후 프로덕션 출시 신청
   - 조직 계정이면 바로 프로덕션 트랙에 업로드 → 검토 제출
7. 검토는 보통 수일 정도 걸립니다.

## 업로드 키 (매우 중요)

- 키 파일: `android/app/health-planet-upload.keystore`
- 비밀번호: `android/keystore.properties`
- 두 파일은 git에 올라가지 않습니다. **반드시 안전한 곳(USB, 비밀번호 관리자 등)에 백업하세요.**
  분실하면 업데이트 버전을 올릴 때 Google에 업로드 키 재설정을 요청해야 합니다.

## 업데이트 출시 방법
1. `android/app/build.gradle`의 `versionCode`를 1씩 올리고 `versionName` 변경 (예: 2 / "1.1")
2. `./gradlew bundleRelease`
3. Play Console에서 새 버전으로 AAB 업로드
